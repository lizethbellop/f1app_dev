# F1 & F1 Academy Analyzer
An interactive web application designed for fans of Formula 1 and F1 Academy who want to explore racing data, visualize performance trends, and make predictions for upcoming races.

What makes it unique? A virtual mascot companion that offers its own predictions and challenges users to a friendly competition. Based on who gets closer to the real outcome, users earn points and rewards in a gamified system.

Key features include:
	•	Historical race and driver data exploration
	•	Visual analytics and performance comparisons
	•	Predictive models based on real-world data
	•	Interactive mascot that competes with the user
	•	Points and rewards system for accurate predictions

Built using Python for data analysis and machine learning, FastAPI for the backend, and React for the user interface, this app merges sports, data science, and playful interactivity.
